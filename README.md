# 🏹 Odysseus's Bow (오디세우스의 활)

**Odysseus's Bow**는 오디세우스 신화 속 활에서 영감을 받은 웹 인터랙티브 사운드 아트 웹앱입니다.  
화면에서 활시위를 걸고(**STRING A BOW**), 부드러운 황금 시위를 튕겨 연주하는(**PLUCK A BOW**) 2단계 인터랙션을 체험할 수 있습니다.

---

## 🌐 바로 실행하기 (웹 라이브 주소)

별도의 설치 없이 모바일 스마트폰이나 PC 브라우저에서 아래 주소로 접속하면 즉시 체험할 수 있습니다:

👉 **[https://parkjae.github.io/odysseus-bow/](https://parkjae.github.io/odysseus-bow/)**

## 📖 사용 방법 가이드 (User Guide)

### 1️⃣ 사운드 활성화 (Audio Unlock)
- 화면 중앙의 **`화면을 터치하여 사운드 활성화`** 안내 버튼을 클릭/터치하면 풍부한 오디오 효과음이 켜집니다.

---

### 2️⃣ 1단계: STRING A BOW (활시위 걸기)
- **목표**: 하단에 연결된 링(Ring)을 위로 끌어올려 상단의 목표 지점(Target Dot)까지 장착하세요.
- **조작 방법**:
  - 화면 하단의 **하얀 링**을 마우스나 손가락으로 누른 채 상단 **하얀 점** 방향으로 쓱 당겨 올립니다.
- **사운드 피드백**:
  - 링을 올리는 진행률 **1/5 지점(20%)**과 **3/5 지점(60%)**을 지날 때 시위가 팽팽해지는 효과음이 울립니다.
- **다음 단계 전환**:
  - 상단 목표 점에 링이 도달하면 사운드 완결과 함께 아름다운 황금 활시위 단계(**PLUCK A BOW**)로 부드럽게 자동 전환됩니다.

---

### 3️⃣ 2단계: PLUCK A BOW (황금 활시위 연주)
- **목표**: 화면에 팽팽하게 걸린 황금 활시위(`#E5B409`)를 자유롭게 튕기며 연주하세요.
- **조작 방법**:
  - 얇은 현을 직접 맞출 필요 없이, **화면 아무 곳이나 마우스/손가락으로 잡고 좌우로 끌었다 놓으세요.** (전역 터치 지원)
- **물리 및 visual 이펙트**:
  - 자연스럽고 부드러운 삼각함수 **스플라인(Spline) 물리 엔진**이 적용되어 손길에 따라 현이 매끈하게 늘어납니다.
  - 현을 튕길 때마다 화려한 황금 입자(Particle Burst) 이펙트와 함께 연주 사운드가 울립니다.
- **🔄 다시 시작하기 (Reload)**:
  - 우측 하단의 **새로고침(Reload) 버튼**을 누르면 언제든지 1단계 **STRING A BOW**로 돌아갑니다.
